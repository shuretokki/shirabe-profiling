In this tutorial, you build a report for a table of homes, open it in your browser, and read its list of alerts. An alert is a flagged problem in a column.

## What you need

- Python 3.10 or newer
- About 5 minutes

::note
The sample table needs shirabe-profiling 0.2.0 or newer.
::

::steps

### Install the package

Install shirabe-profiling from PyPI:

```bash
pip install shirabe-profiling
```

Make sure that the sample table loads:

```bash
python -c "from shirabe_profiling.datasets import make_homes"
```

The command prints nothing when it works.

### Build the sample table

Open a Python file or a notebook, and build a table of 2,000 homes:

```python
from shirabe_profiling.datasets import make_homes

df = make_homes()
print(df.shape)
```

```text
(2000, 11)
```

The table has 11 columns. Look at three of them:

```python
print(df.select("district", "area_m2", "price").head(3))
```

```text
shape: (3, 3)
┌──────────┬─────────┬────────┐
│ district ┆ area_m2 ┆ price  │
│ ---      ┆ ---     ┆ ---    │
│ str      ┆ i64     ┆ i64    │
╞══════════╪═════════╪════════╡
│ Cibubur  ┆ 181     ┆ 516000 │
│ Depok    ┆ 170     ┆ 894000 │
│ Bekasi   ┆ 65      ┆ 179000 │
└──────────┴─────────┴────────┘
```

The same call always builds the same table, so your output matches this page.

### Write the report

Profile the table and write the report to a file:

```python
from shirabe_profiling import ProfileReport

report = ProfileReport(df)
report.to_html("report.html")
print(report)
```

```text
ProfileReport(title='Dataset Report', rows=2000, columns=11)
```

### Open the report

Open `report.html` in your browser. The report needs an internet connection to display correctly.

The Dataset Overview comes first, and the Alerts section sits under it.

:u-color-mode-image{light="/images/report-overview.png" dark="/images/report-overview-dark.png" alt="The overview of the report, with the facts of the table and the list of alerts"}

### Read the alerts

Print the same alerts in code:

```python
for alert in report.alerts:
    print(alert.alert_type.name, alert.column)
```

```text
HIGH_CARDINALITY listing_id
HIGH_ZEROS garage_spaces
IMBALANCED has_pool
HIGH_MISSING lot_m2
SKEWED price
SKEWED agent_commission
HIGH_CORRELATION agent_commission
HIGH_CORRELATION area_m2
```

Each line names a problem and a column. The column `listing_id` has a different value in every row, so it raises the High Cardinality alert. The column `lot_m2` raises High Missing, because 8.9% of its values are missing.

Open the Guide tab of the report next. It explains each alert and lists some possible fixes.

::

## Remember

- `ProfileReport(df)` profiles a table, and `to_html` writes the report to a file.
- The report is one HTML file that you open in a browser.
- An alert names a column and a problem, and `report.alerts` lists them in code.
- The Guide tab explains each alert.
