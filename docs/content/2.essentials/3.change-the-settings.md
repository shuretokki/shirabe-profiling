Pass a setting to `ProfileReport` to change what the report flags, or put the settings in a `ProfileConfig` to reuse them. Every setting has a default, so you change only the ones you need.

## Prerequisites

- shirabe-profiling 0.2.0 or newer
- A table to profile. This guide uses the homes table.

## Steps

::steps

### Seeing the default result

Default limit for missing values is 0.05. Print the columns that pass it to see the starting point:

```python
from shirabe_profiling import ProfileReport
from shirabe_profiling.datasets import make_homes

df = make_homes()
report = ProfileReport(df)
print([(a.column, round(a.value, 3)) for a in report.alerts if a.alert_type.name == "HIGH_MISSING"])
```

```text
[('lot_m2', 0.089)]
```

### Raising the limit

Pass `missing_threshold` to see the alert go away. With 0.1, a column needs more than 10% missing values to raise it:

```python
loose = ProfileReport(df, missing_threshold=0.1)
print([a.column for a in loose.alerts if a.alert_type.name == "HIGH_MISSING"])
```

```text
[]
```

### Keeping settings in one object

Build a `ProfileConfig` to share the same settings between reports, then pass it as `config`:

```python
from shirabe_profiling import ProfileConfig

config = ProfileConfig(title="Homes", mode="overview", missing_threshold=0.1)
quick = ProfileReport(df, config=config)
print(quick.config.title)
```

```text
Homes
```

`overview` mode skips the slow parts, so correlations and interactions are empty:

```python
print(list(quick.correlations), quick.interactions)
```

```text
[] None
```

::

## Changing a config

A `ProfileConfig` is frozen, so you cannot assign to its fields. Assigning raises a `FrozenInstanceError`:

```python
config.title = "Other"
```

```text
dataclasses.FrozenInstanceError: cannot assign to field 'title'
```

Use `dataclasses.replace` to make a copy with one field changed:

```python
import dataclasses

changed = dataclasses.replace(config, title="Other")
print(changed.title, changed.mode, changed.missing_threshold)
```

```text
Other overview 0.1
```

## Troubleshooting

If a keyword has no effect, check that you did not also pass `config`. When you pass a `config`, the report ignores the other keywords:

```python
ignored = ProfileReport(df, config=ProfileConfig(), missing_threshold=0.5)
print([a.column for a in ignored.alerts if a.alert_type.name == "HIGH_MISSING"])
```

```text
['lot_m2']
```

Put the setting in the config instead.

If you see `ValueError: missing_threshold must be in [0, 1], got 2`, the value is out of range. Pass a share between 0 and 1.
