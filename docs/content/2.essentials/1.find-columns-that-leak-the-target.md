Use the Target Leakage alert to find columns that hold information you know only after the target is known. A model that trains on such a column looks accurate and fails on new data.

## Prerequisites

- shirabe-profiling 0.2.0 or newer
- A table with a target column. This guide uses the homes table, where `price` is the target.

## Steps

::steps

### Naming a target

Pass the name of the target column to `ProfileReport`:

```python
from shirabe_profiling import ProfileReport
from shirabe_profiling.datasets import make_homes

df = make_homes()
report = ProfileReport(df, target="price")
```

### Listing Target Leakage alerts

Print the alerts of this type:

```python
for alert in report.alerts:
    if alert.alert_type.name == "TARGET_LEAKAGE":
        print(alert.column, round(alert.value, 3))
```

```text
agent_commission 0.999
```

Read the value as the link between the column and the target, from 0 to 1. A link of 0.95 or more raises the alert.

### Reading the ranking

Print the ranking to see the strongest links first:

```python
for link in report.target.links[:3]:
    print(link.column, round(link.association, 3))
```

```text
agent_commission 0.999
area_m2 0.675
lot_m2 0.588
```

Look for a link far above the rest, as here, because it points to a leak.

### Deciding if a column leaks

Ask when you know the value of the column. An agent is paid a commission after a home sells, so you do not know it when you predict a price. Remove this column.

If you know a column at the time of the prediction, keep it, even when its link is high.

### Removing the column and rerunning the report

```python
clean = ProfileReport(df.drop("agent_commission"), target="price")
print([a.column for a in clean.alerts if a.alert_type.name == "TARGET_LEAKAGE"])
```

```text
[]
```

::

## Confirming the leak is gone

Make sure that the list of Target Leakage alerts is empty, and that the strongest link is now `area_m2`:

```python
print(clean.target.links[0].column)
```

```text
area_m2
```

## Changing the limit

To see weaker links as alerts, lower `leakage_threshold`. Default is 0.95. With 0.6, the column `area_m2` raises the alert at 0.675:

```python
loose = ProfileReport(df.drop("agent_commission"), target="price", leakage_threshold=0.6)
print([(a.column, round(a.value, 3)) for a in loose.alerts if a.alert_type.name == "TARGET_LEAKAGE"])
```

```text
[('area_m2', 0.675)]
```

Use a low limit only to explore, because a column such as `area_m2` is a normal feature.

## Troubleshooting

If you see the error `target 'cost' is not a column of the data`, the name does not match a column. Copy the name from the list of columns in the message.
