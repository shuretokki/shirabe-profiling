A leaking column holds information that you know only after the target is known. A model that trains on it looks accurate and fails on new data. This guide finds those columns with the Target Leakage alert.

## Prerequisites

- shirabe-profiling 0.2.0 or newer
- A table with a target column. This guide uses the homes table, where `price` is the target.

## Steps

::steps

### Name the target

Pass the name of the target column to `ProfileReport`:

```python
from shirabe_profiling import ProfileReport
from shirabe_profiling.datasets import make_homes

df = make_homes()
report = ProfileReport(df, target="price")
```

### List the Target Leakage alerts

Print the alerts of this type:

```python
for alert in report.alerts:
    if alert.alert_type.name == "TARGET_LEAKAGE":
        print(alert.column, round(alert.value, 3))
```

```text
agent_commission 0.999
```

The alert fires when the link between a column and the target is 0.95 or more. The value is that link, from 0 to 1.

### Read the ranking

The ranking puts the strongest links first:

```python
for link in report.target.links[:3]:
    print(link.column, round(link.association, 3))
```

```text
agent_commission 0.999
area_m2 0.675
lot_m2 0.588
```

A link far above the rest, as here, points to a leak.

### Decide if the column leaks

Ask when you know the value of the column. An agent is paid a commission after a home sells, so you do not know it when you predict a price. Remove this column.

If you know a column at the time of the prediction, keep it, even when its link is high.

### Remove the column and run the report again

```python
clean = ProfileReport(df.drop("agent_commission"), target="price")
print([a.column for a in clean.alerts if a.alert_type.name == "TARGET_LEAKAGE"])
```

```text
[]
```

::

## Make sure that the leak is gone

The list of Target Leakage alerts is empty. The strongest link is now `area_m2`:

```python
print(clean.target.links[0].column)
```

```text
area_m2
```

## Change the limit

To see weaker links as alerts, lower `leakage_threshold`. The default is 0.95. With 0.6, the column `area_m2` raises the alert at 0.675:

```python
loose = ProfileReport(df.drop("agent_commission"), target="price", leakage_threshold=0.6)
print([(a.column, round(a.value, 3)) for a in loose.alerts if a.alert_type.name == "TARGET_LEAKAGE"])
```

```text
[('area_m2', 0.675)]
```

Use a low limit only to explore. A column such as `area_m2` is a normal feature.

## Troubleshooting

The error `target 'cost' is not a column of the data` means that the name does not match a column. The message lists the columns, so copy the name from there.
