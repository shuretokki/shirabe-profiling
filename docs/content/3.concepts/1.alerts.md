Read an alert as a flag on a column, a pair of columns, or a whole table that needs a look before you trust the data. Each alert has a type, a value, and a limit that you can change.

## Lists of alerts

| Alert | Covers | Raised when | Default |
| --- | --- | --- | --- |
| `HIGH_MISSING` | Every column | Share of missing values is above the limit | `missing_threshold=0.05` |
| `CONSTANT` | Numeric, categorical, datetime, and text columns | Column has at most this many distinct values, and at least one value | `constant_threshold=1` |
| `HIGH_CARDINALITY` | Numeric and categorical columns | Share of distinct values is above the limit | `cardinality_threshold=0.95` |
| `DUPLICATES` | Whole table | Share of duplicate rows is above the limit, so any duplicate row raises it | `duplicate_threshold=0.0` |
| `HIGH_ZEROS` | Numeric columns | Share of zeros is above the limit | `zero_threshold=0.05` |
| `SKEWED` | Numeric columns | Absolute skewness is above the limit | `skewness_threshold=2.0` |
| `IMBALANCED` | Categorical and boolean columns | Most common value holds a share above the limit | `imbalance_threshold=0.9` |
| `HIGH_CORRELATION` | A pair of columns | Absolute correlation is above the limit | `correlation_threshold=0.8` |
| `UNIFORM` | Categorical columns | A chi-squared test cannot reject that the top values are evenly spread, so the p-value is above the limit | `uniform_pvalue_threshold=0.05` |
| `TARGET_LEAKAGE` | Any column, when you name a target | Link to the target is at or above the limit | `leakage_threshold=0.95` |

Pass a setting as a keyword to `ProfileReport`. Follow [Change the settings](/essentials/change-the-settings) to see how.

## Listing alerts in a report

Print the type, the column, and the value of every alert to see what the report found:

```python
from shirabe_profiling import ProfileReport
from shirabe_profiling.datasets import make_homes

report = ProfileReport(make_homes(), target="price")
for alert in report.alerts:
    print(alert.column, alert.alert_type.name, round(alert.value, 3))
```

```text
listing_id HIGH_CARDINALITY 1.0
agent_commission HIGH_CORRELATION 0.999
area_m2 HIGH_CORRELATION 0.887
lot_m2 HIGH_MISSING 0.089
garage_spaces HIGH_ZEROS 0.34
has_pool IMBALANCED 0.966
price SKEWED 2.283
agent_commission SKEWED 2.282
agent_commission TARGET_LEAKAGE 0.999
```

`DUPLICATES` has no column, so `alert.column` is `None`.

Alerts are sorted by type name, then by value from highest to lowest, and by column name when two values are equal. The Alerts section of the report uses the same order, so the worst column of each type comes first.

## Reading the value

Each alert type sets its own value.

| Alert | Value |
| --- | --- |
| `HIGH_MISSING` | Share of missing values, from 0 to 1 |
| `CONSTANT` | Number of distinct values |
| `HIGH_CARDINALITY` | Share of distinct values, from 0 to 1 |
| `DUPLICATES` | Share of duplicate rows, from 0 to 1 |
| `HIGH_ZEROS` | Share of zeros, from 0 to 1 |
| `SKEWED` | Absolute skewness, so the sign is dropped |
| `IMBALANCED` | Share of the most common value, from 0 to 1 |
| `HIGH_CORRELATION` | Absolute correlation, from 0 to 1 |
| `UNIFORM` | P-value of the test |
| `TARGET_LEAKAGE` | Link to the target, from 0 to 1 |

Some alerts add facts to `alert.details`. A `HIGH_CORRELATION` alert names the other column and the method, and a `TARGET_LEAKAGE` alert names that target:

```python
for alert in report.alerts:
    if alert.alert_type.name == "HIGH_CORRELATION":
        print(alert.column, alert.details)
```

```text
agent_commission {'column_b': 'price', 'method': 'phik'}
area_m2 {'column_b': 'lot_m2', 'method': 'phik'}
```

## Understanding rules

- **Correlation pairs.** Each pair is checked once, with Phi K when available and Pearson if not.
- **Uniform columns.** Only the top values are counted, five by default, and a column with fewer than two is skipped. Change the number with `n_top_values`.
- **Constant columns.** A boolean column cannot raise `CONSTANT`, but it can raise `IMBALANCED`.
- **Target leakage.** Checked only when you name a target. Learn more in [Find columns that leak the target](/essentials/find-columns-that-leak-the-target).
