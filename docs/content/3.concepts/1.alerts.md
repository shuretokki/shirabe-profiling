Read an alert as a flag on a column, a pair of columns, or the whole table that needs a look before you trust the data. Each alert has a type, a value, and a limit that you can change.

## The ten alerts

| Alert | Covers | Raised when | Setting (default) |
| --- | --- | --- | --- |
| `HIGH_MISSING` | Every column | The share of missing values is above the limit | `missing_threshold` (0.05) |
| `CONSTANT` | Numeric, categorical, datetime, and text columns | The column has at most this many distinct values, and at least one value | `constant_threshold` (1) |
| `HIGH_CARDINALITY` | Numeric and categorical columns | The share of distinct values is above the limit | `cardinality_threshold` (0.95) |
| `DUPLICATES` | The whole table | The share of duplicate rows is above the limit, so any duplicate row raises it | `duplicate_threshold` (0.0) |
| `HIGH_ZEROS` | Numeric columns | The share of zeros is above the limit | `zero_threshold` (0.05) |
| `SKEWED` | Numeric columns | The absolute skewness is above the limit | `skewness_threshold` (2.0) |
| `IMBALANCED` | Categorical and boolean columns | The most common value holds a share above the limit | `imbalance_threshold` (0.9) |
| `HIGH_CORRELATION` | A pair of columns | The absolute correlation is above the limit | `correlation_threshold` (0.8) |
| `UNIFORM` | Categorical columns | A chi-squared test cannot reject that the top values are evenly spread, so the p-value is above the limit | `uniform_pvalue_threshold` (0.05) |
| `TARGET_LEAKAGE` | Any column, when you name a target | The link to the target is at or above the limit | `leakage_threshold` (0.95) |

Pass a setting as a keyword to `ProfileReport`. Follow [Change the settings](/essentials/change-the-settings) to see how.

## List the alerts of a report

Print the type, the column, and the value of every alert to see what the report found:

```python
from shirabe_profiling import ProfileReport
from shirabe_profiling.datasets import make_homes

report = ProfileReport(make_homes(), target="price")
for alert in report.alerts:
    print(alert.column, alert.alert_type.name, round(alert.value, 3))
```

```text
listing_id HIGH_CARDINALITY 1.0
garage_spaces HIGH_ZEROS 0.34
has_pool IMBALANCED 0.966
lot_m2 HIGH_MISSING 0.089
price SKEWED 2.283
agent_commission SKEWED 2.282
agent_commission HIGH_CORRELATION 0.999
area_m2 HIGH_CORRELATION 0.887
agent_commission TARGET_LEAKAGE 0.999
```

The `DUPLICATES` alert has no column, so `alert.column` is `None`.

## Read the value

The value depends on the type of the alert.

| Alert | The value is |
| --- | --- |
| `HIGH_MISSING` | The share of missing values, from 0 to 1 |
| `CONSTANT` | The number of distinct values |
| `HIGH_CARDINALITY` | The share of distinct values, from 0 to 1 |
| `DUPLICATES` | The share of duplicate rows, from 0 to 1 |
| `HIGH_ZEROS` | The share of zeros, from 0 to 1 |
| `SKEWED` | The absolute skewness, so the sign is dropped |
| `IMBALANCED` | The share of the most common value, from 0 to 1 |
| `HIGH_CORRELATION` | The absolute correlation, from 0 to 1 |
| `UNIFORM` | The p-value of the test |
| `TARGET_LEAKAGE` | The link to the target, from 0 to 1 |

Some alerts add facts to `alert.details`. A `HIGH_CORRELATION` alert names the other column and the method, and a `TARGET_LEAKAGE` alert names the target:

```python
for alert in report.alerts:
    if alert.alert_type.name == "HIGH_CORRELATION":
        print(alert.column, alert.details)
```

```text
agent_commission {'column_b': 'price', 'method': 'phik'}
area_m2 {'column_b': 'lot_m2', 'method': 'phik'}
```

## How the rules work

- **Correlation pairs.** The report checks each pair once. It uses Phi K when the report has it, and Pearson if not.
- **Uniform columns.** The test counts the top values only, five by default, and skips a column with fewer than two of them. Change the number with `n_top_values`.
- **Constant columns.** A boolean column cannot raise `CONSTANT`, but it can raise `IMBALANCED`.
- **Target leakage.** The report checks this alert only when you name a target. Learn more in [Find columns that leak the target](/essentials/find-columns-that-leak-the-target).
