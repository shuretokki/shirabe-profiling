Create a `ProfileReport` to run every analysis once, and then call its methods to write the report or to read the numbers.

```python
from shirabe_profiling import ProfileReport
```

## Create a report

```python
ProfileReport(source, *, title="Dataset Report", mode="complete", config=None, **kwargs)
```

| Argument | Type | Default | Description |
|:---|:---|:---|:---|
| `source` | Polars DataFrame, Polars LazyFrame, pandas DataFrame, or a path | required | Table to profile. See the accepted inputs below. |
| `title` | `str` | `"Dataset Report"` | Title of the report. |
| `mode` | `"complete"` or `"overview"` | `"complete"` | Depth of the profile. Overview mode skips the slow parts. |
| `config` | `ProfileConfig` or `None` | `None` | A full configuration. When you pass it, `title`, `mode`, and `**kwargs` are ignored. |
| `**kwargs` | any option of `ProfileConfig` | none | Passed to `ProfileConfig`, such as `target="price"`. |

## Accepted inputs

| Input | How it is read |
|:---|:---|
| `polars.DataFrame` | Used as it is. |
| `polars.LazyFrame` | Collected into a DataFrame. |
| `pandas.DataFrame` | Converted with `polars.from_pandas`. This needs pandas installed. |
| A `str` or `Path` that ends in `.csv` | Read with `polars.read_csv`. |
| A `str` or `Path` that ends in `.tsv` | Read with `polars.read_csv` and a tab as the separator. |
| A `str` or `Path` that ends in `.parquet` | Read with `polars.read_parquet`. |

File name endings are not case-sensitive.

| Error | Message |
|:---|:---|
| `TypeError` | `Unsupported input type: float. Expected pl.DataFrame, pl.LazyFrame, pd.DataFrame, or a file path (str/Path).` The type name changes with the input. |
| `FileNotFoundError` | `File not found: nope.csv` |
| `ValueError` | `Unsupported file format: '.xlsx'. Supported: .csv, .parquet, .tsv` |
| `ValueError` | `Failed to convert Pandas DataFrame to Polars:` followed by the cause. |

An option with a value out of range raises a `ValueError` that names the option.

## Methods

### `to_html(path=None)`

Returns the report as an HTML string. When you pass `path`, the method also writes the string to that file in UTF-8.

### `to_json(path=None, indent=2)`

Returns the result of `to_dict()` as a JSON string. Column types appear as their names. When you pass `path`, the method also writes the string to that file in UTF-8.

### `to_dict()`

Returns a dictionary with these keys:

| Key | Content |
|:---|:---|
| `title` | Title of the report. |
| `overview` | Facts about the table. Same as the `overview` property. |
| `columns` | Statistics of each column. Same as the `stats` property. |
| `alerts` | A list of dictionaries with `column`, `alert_type` (the name), `value`, and `details`. |
| `correlations` | For each method, the `matrix` as a list of rows, and the `pvalues` when the method has them. |
| `interactions` | Data of the Interactions section, or `None`. |
| `target` | Target analysis as a dictionary, or `None`. |

## Properties

| Property | Type | Description |
|:---|:---|:---|
| `config` | `ProfileConfig` | Configuration that the report uses. |
| `df` | `polars.DataFrame` | Table, after loading. |
| `column_types` | `dict[str, ColumnType]` | Inferred type of each column. |
| `overview` | `dict` | Facts about the table, such as `n_rows`, `n_columns`, `missing_cells`, `missing_cells_pct`, `duplicate_rows`, `duplicate_rows_pct`, and `memory_human`. |
| `alerts` | `list[Alert]` | Every alert, in the order that the report finds them. |
| `stats` | `dict[str, dict]` | Statistics of each column, by column name. The keys depend on the column type. A numeric column has `count`, `missing_count`, `mean`, `median`, `skewness`, `zeros_count`, and more. |
| `correlations` | `dict[str, CorrelationResult]` | Matrices, by method name. The methods that apply to the table appear, such as `phik`, `pearson`, `spearman`, and `kendall`. The dictionary is empty in overview mode. |
| `interactions` | `InteractionData` or `None` | Data of the Interactions section. It is `None` in overview mode. |
| `target` | `TargetAnalysis` or `None` | Target analysis. It is `None` when you do not pass a target. |

### Alert

An `Alert` has four fields:

| Field | Type | Description |
|:---|:---|:---|
| `column` | `str` or `None` | Column of the alert. It is `None` for an alert about the whole table, such as duplicate rows. |
| `alert_type` | `AlertType` | Kind of alert. Use `alert_type.name` for its name. |
| `value` | `float` | Measured value, such as the share of missing values. |
| `details` | `dict` | More facts. A High Correlation alert holds `column_b` and `method`. A Target Leakage alert holds `target`. |

### TargetAnalysis

A `TargetAnalysis` has five fields:

| Field | Description |
|:---|:---|
| `summary` | Facts about the target. `summary.task` is `"regression"` or `"classification"`. |
| `links` | A list of `FeatureLink`, the strongest link first. A `FeatureLink` has `column`, `kind`, `association`, and `direction`. |
| `breakdowns` | Values of the target for each group of a column. |
| `missing_links` | Target in the rows where a column is missing, compared with the other rows. |
| `skipped` | Names of the columns that are not numeric and have more than 50 distinct values. The ranking leaves them out, because a link to such a column is likely by chance. |

## Text form

Print the report to see its title and the size of its table:

```text
ProfileReport(title='Dataset Report', rows=2000, columns=11)
```
