Call `make_homes` to get a table of homes for sale, with a price to predict and one column that leaks it. Use it to try the report before you load your own data. The table is synthetic, so it has no real people or addresses.

```python
from shirabe_profiling.datasets import make_homes
```

## Creating a table

```python
make_homes(n=2000, *, seed=7, nulls=0.09)
```

| Argument | Type | Default | Description |
|:---|:---|:---|:---|
| `n` | `int` | `2000` | Number of rows. It must be 1 or more. |
| `seed` | `int` | `7` | Seed of the random generator. It must be 0 or more. |
| `nulls` | `float` | `0.09` | Share of rows with a missing `lot_m2`, from 0 to 1. |

The same seed always gives the same table, and another seed gives another table. The function returns a `polars.DataFrame`.

Print the shape to see the size of the default table:

```python
df = make_homes()
print(df.shape)
```

```text
(2000, 11)
```

## Reading the columns

| Column | Type | Description |
|:---|:---|:---|
| `listing_id` | `Int64` | Running number that starts at 5000. Every value is different. |
| `district` | `String` | One of `Menteng`, `Kemang`, `Tebet`, `Cibubur`, `Bekasi`, and `Depok`. |
| `area_m2` | `Int64` | Floor area in square meters, from 24 to 600. |
| `bedrooms` | `Int64` | Number of bedrooms, from 1 to 7. It grows with the area. |
| `garage_spaces` | `Int64` | Number of garage spaces, from 0 to 3. About a third of the homes have none. |
| `has_pool` | `Boolean` | `True` for about 4% of the homes. |
| `lot_m2` | `Float64` | Lot area in square meters. About 9% of the values are missing, set by `nulls`. |
| `year_built` | `Int64` | Year of construction, from 1975 to 2024. |
| `listed_on` | `Date` | Day of the listing, from 2023-01-01 and within 1000 days after it. |
| `price` | `Int64` | Sale price, rounded to 1000. This is the target. |
| `agent_commission` | `Int64` | 2.5% of the price, rounded to 1000. |

The price grows with the area, the district, the garage, and the pool, and it falls with the age of the home. It is skewed, so the Target section suggests a log transform.

`agent_commission` leaks the target on purpose. An agent earns a commission after a home sells, so you do not know it when you predict a price. Follow [Find columns that leak the target](/essentials/find-columns-that-leak-the-target) to find it with the report.

## Handling errors

An argument outside its range raises a `ValueError` that names the argument and shows the value.

| Call | Error |
|:---|:---|
| `make_homes(n=0)` | `n must be an integer >= 1, got 0` |
| `make_homes(seed=-1)` | `seed must be an integer >= 0, got -1` |
| `make_homes(nulls=1.5)` | `nulls must be between 0 and 1, got 1.5` |
