## What is shirabe-profiling?

shirabe-profiling is a fast, Polars-native Python library that profiles data tables, outputs clean and shareable HTML reports, and features an integrated alert system to flag critical data quality issues immediately.

:color-mode-video{name="/images/report-scroll" alt="A report scrolling from the overview to the last section"}

## Key features

- Quality alerts: open the Alerts section to find missing values, constant columns, skewed columns, and high correlations.
- A guide for every alert: open the Guide tab to see the limit of each alert, some possible fixes, and the sources.
- A target section: name the column that you want to predict to see how each column links to it, and to get a warning about leakage.
- Skew tabs: open a skewed column to compare its chart with transformed versions.
- Results in code: call `to_dict`, `to_json`, `stats`, or `alerts` to read the numbers.
- Many inputs: pass a Polars DataFrame or LazyFrame, a pandas DataFrame, or the path of a CSV, TSV, or Parquet file.
- Two themes: switch between dark and light in the settings menu.

## Seeing what the report shows

- Dataset Overview: the number of rows and columns, the missing cells, the duplicate rows, and the types of the columns.
- Alerts: the flagged problems, grouped by type.
- Variables: a sortable table of the columns.
- Column Details: the chart and the statistics of each column.
- Interactions: scatter plots and box plots for pairs of columns.
- Correlations: a heatmap for each method, and the strongest pairs.
- Missing Patterns and Outliers: tables of the columns that miss values together and of the values far from the rest.
- Sample: the first rows, the last rows, random rows, and the rows with the most gaps.
- Target: the link of each column to the target. This section appears when you name a target.
