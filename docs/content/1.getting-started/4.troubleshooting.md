## Input errors

### Unsupported input type

```text
Unsupported input type: float. Expected pl.DataFrame, pl.LazyFrame, pd.DataFrame, or a file path (str/Path).
```

If you see this error, you passed a value that is not a table or a path. The type name in the message changes with the value. Pass a Polars frame, a pandas frame, or the path of a file.

### File not found

```text
File not found: nope.csv
```

If you see this error, the path does not exist from the folder where Python runs. Use the full path of the file, or start Python in the folder of the file.

### Unsupported file format

```text
Unsupported file format: '.xlsx'. Supported: .csv, .parquet, .tsv
```

If you see this error, the file ends in a type that the library does not read. Load the file with Polars yourself and pass the frame, or save the file as CSV, TSV, or Parquet.

## Target errors

### The target is not a column

```text
target 'cost' is not a column of the data. Columns: listing_id, district, area_m2, bedrooms, garage_spaces, has_pool, lot_m2, year_built, listed_on, price, ...
```

If you see this error, the name does not match a column. Copy the name from the list of columns in the message. The list shows the first 10 columns.

### The target has a wrong type

```text
target 'listed_on' has type DATETIME. Use a numeric, boolean or category column.
```

If you see this error, the target is a column of a type that the target analysis does not read. Pick a numeric, boolean, or category column as the target.

### The target has no values

```text
target 'price' has no values
```

If you see this error, every value of the target column is missing. Fill the column or pick another target.

## Option errors

### A value is out of range

```text
mode must be one of ('complete', 'overview'), got 'fast'
```

```text
histogram_bins must be >= 2, got 1
```

If you see an error like these, read the name of the option at the start of the message, and pass a value in the range that the message gives.

### An option does not exist

```text
TypeError: ProfileConfig.__init__() got an unexpected keyword argument 'colour'
```

If you see this error, the name is not an option of `ProfileConfig`. Check the spelling of the option.

## The report

### The report does not display correctly

If the report does not display correctly in your browser, make sure that your computer has an internet connection. The report loads its charts and styles from the internet.
