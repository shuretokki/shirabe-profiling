## Installation issues

### Sample table is missing

If you see `ModuleNotFoundError: No module named 'shirabe_profiling.datasets'`, your installed version is older than 0.2.0, which is the first version with the sample table.

Upgrade the package:

::code-group

```bash [pip]
pip install --upgrade shirabe-profiling
```

```bash [uv]
uv add --upgrade-package shirabe-profiling shirabe-profiling
```

::

Outside a uv project, run `uv pip install --upgrade shirabe-profiling` instead.

Then print the version, and make sure that it is 0.2.0 or newer:

```bash [Terminal]
python -c "import shirabe_profiling; print(shirabe_profiling.__version__)"
```

## Input issues

### A pandas table does not convert

If you see an error that starts with `Failed to convert Pandas DataFrame to Polars: pyarrow is required`, the table has columns that Polars can read only with pyarrow, such as text, categories, or nullable integers.

Install the pandas extra, which adds pyarrow:

::code-group

```bash [pip]
pip install "shirabe-profiling[pandas]"
```

```bash [uv]
uv add "shirabe-profiling[pandas]"
```

::

Outside a uv project, run `uv pip install "shirabe-profiling[pandas]"` instead.

A table of integer, float, boolean, or date columns converts without pyarrow.

## Report issues

### Report does not display correctly

If the report does not display correctly in your browser, make sure that your computer has an internet connection. It loads its charts and styles from the internet.
