## Requirements

- Python 3.10 or newer

The package installs its own dependencies: Polars, NumPy, SciPy, phik, polars-statistics, and Jinja2.

## Install from PyPI

::steps

### Check your Python version

```bash
python --version
```

Make sure that the version is 3.10 or newer.

### Install the package

```bash
pip install shirabe-profiling
```

### Make sure that it works

```bash
python -c "import shirabe_profiling"
```

If the import works, this command prints nothing.

::

Install version 0.2.0 or newer to use the sample table `make_homes`, which the next pages use.
