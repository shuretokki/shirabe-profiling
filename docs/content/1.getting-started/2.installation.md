## Requirements

- Python 3.10 or newer

## Installing from PyPI

::steps

### Checking your Python version

```bash
python --version
```

Make sure that the version is 3.10 or newer.

### Installing the package

::code-group

```bash [pip]
pip install shirabe-profiling
```

```bash [uv]
uv add shirabe-profiling
```

::

In a uv project, `uv add` adds the package to `pyproject.toml`. In a plain virtual environment, run `uv pip install shirabe-profiling` instead.

### Checking the install

```bash
python -c "import shirabe_profiling"
```

::

## Installing the pandas extra

Install the `pandas` extra to profile pandas tables with text, category, or nullable integer columns. It adds pyarrow, which Polars needs to read those columns.

::code-group

```bash [pip]
pip install "shirabe-profiling[pandas]"
```

```bash [uv]
uv add "shirabe-profiling[pandas]"
```

::

A table of integer, float, boolean, or date columns converts without the extra.
