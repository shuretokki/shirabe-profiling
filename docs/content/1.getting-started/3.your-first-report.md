Build a report for a table of homes, open it in your browser, and read its list of alerts. An alert is a flagged problem in a column.

## What you need

- Python 3.10 or newer
- shirabe-profiling 0.2.0 or newer, from [Installation](/getting-started/installation)

::steps

### Build the sample table

Open a Python file or a notebook, and build a table of 2,000 homes:

```python
from shirabe_profiling.datasets import make_homes

df = make_homes()
print(df.shape)
```

```text
(2000, 11)
```

Look at three of its 11 columns:

```python
print(df.select("district", "area_m2", "price").head(3))
```

```text
shape: (3, 3)
┌──────────┬─────────┬────────┐
│ district ┆ area_m2 ┆ price  │
│ ---      ┆ ---     ┆ ---    │
│ str      ┆ i64     ┆ i64    │
╞══════════╪═════════╪════════╡
│ Cibubur  ┆ 181     ┆ 516000 │
│ Depok    ┆ 170     ┆ 894000 │
│ Bekasi   ┆ 65      ┆ 179000 │
└──────────┴─────────┴────────┘
```

Run the call again to get the same table, so your output matches this page.

### Write the report

Profile the table and write the report to a file:

```python
from shirabe_profiling import ProfileReport

report = ProfileReport(df)
report.to_html("report.html")
print(report)
```

```text
ProfileReport(title='Dataset Report', rows=2000, columns=11)
```

### Open the report

Open `report.html` in your browser with an internet connection on, because the report loads its charts and styles from the internet.

Find the Dataset Overview at the top and the Alerts section under it.

:u-color-mode-image{light="/images/report-overview.png" dark="/images/report-overview-dark.png" alt="The overview of the report, with the facts of the table and the list of alerts" class="rounded-md border border-default"}

### Read the alerts

Print the same alerts in code:

```python
for alert in report.alerts:
    print(alert.alert_type.name, alert.column)
```

```text
HIGH_CARDINALITY listing_id
HIGH_ZEROS garage_spaces
IMBALANCED has_pool
HIGH_MISSING lot_m2
SKEWED price
SKEWED agent_commission
HIGH_CORRELATION agent_commission
HIGH_CORRELATION area_m2
```

Read each line as a problem and a column. For example, `listing_id` has a different value in every row, which raises High Cardinality, and `lot_m2` is missing 8.9% of its values, which raises High Missing.

Open the Guide tab next to see each alert explained, with some possible fixes.

::

## Remember

- Call `ProfileReport(df)` to profile a table, and `to_html` to write the report to a file.
- Open the report, one HTML file, in any browser.
- Read `report.alerts` in code to list each alert as a column and a problem.
- Open the Guide tab to learn how to fix an alert.
